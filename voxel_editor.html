Flatten area

Drag a rectangle on the minimap or in the 3D view to select an X/Z area, set a target height, then Apply. Everything below the target height becomes solid; everything above becomes empty, within the area.
The selection is drawn into the 3D view as the surface Apply would leave — green where it fills, red where it cuts — and you can draw it there directly instead of on the minimap.
Drag a point to move it. Drag the faint handle at an edge's midpoint to add a point there. Alt-click a point, or use ✕, to delete it — Delete/Backspace removes the selected one.
Samples the current terrain height at each corner/point and interpolates a slope between them, instead of one flat target height. Edit any value to override it, or Resample.

Navigate

Drag = orbit · scroll = zoom · WASD = move focus · Q/E = focus up/down. Click the minimap to jump the focus point. Scroll the minimap to zoom it. While a flatten tool is active the left button draws the selection instead — right-drag still orbits.
Low-detail whole-scene view (each leaf block is one box — no per-voxel surface, no editing here). Click anywhere to jump there and switch back to the detailed, editable view — except with a flatten tool active, where the click draws the selection instead, which is the easy way to pick out a large area.

Height clip

Hide everything above a height so you can see and edit the ground. This only affects the 3D view — editing still works on whatever surface is visible.

Gaussian splats

Fade the voxels down to see the splats through them — that's the quickest way to judge whether the two line up.
Apply the height-clip slider to the splats as well, so both views are cut at the same plane.

Splat alignment

PLY axes → voxel world axes. The default (flip X, flip Y) is what splat-transform's voxelizer produced for the file this was built against; it rotates the scene internally before voxelizing.
